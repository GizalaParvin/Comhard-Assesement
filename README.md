# Task Manager Web App

Practical exam implementation using React (Vite) + plain CSS, Node + Express, and MongoDB with Mongoose.

## Run Commands

### 1. Install dependencies
```bash
# In backend
cd backend
npm install

# In frontend
cd ../frontend
npm install
```

### 2. Run Backend
```bash
cd backend
npm start
```
Server runs on `http://localhost:5000`. (Connects to MongoDB; uses in-memory MongoDB automatically if local MongoDB is not running).

### 3. Run Frontend
```bash
cd frontend
npm run dev
```
App runs on `http://localhost:5173`.
